# Text removed from the manuscript

When Charles replaces a whole section with a shorter version, the text it replaces is kept here, one file per
section, verbatim (with its provenance comments). These files are not part of the manuscript. They serve two purposes:

- a record of the extra analyses that were done for the section, with the make targets and tables behind each
  number, so that a reviewer's question can be answered without redoing the work;
- a stock of supplementary material: each paragraph lists results that can be turned quickly into a supplementary
  note, table or figure if needed.

Each file starts with an index of what the removed paragraphs hold (and how to regenerate it), then the statements
that later work has superseded, then the removed text. The commit that removed the text quotes the replacement
paragraph that Charles provided.
